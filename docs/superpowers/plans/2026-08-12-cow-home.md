**Goal:** Give each spawn container a persistent, copy-on-write home directory seeded from the image, so agents can freely write dotfiles, caches, and config without touching the host `~` and without losing state between runs.

**Architecture:** A host directory (`$XDG_STATE_HOME/spawn/homes/<name>/`) is bind-mounted at `/home/coder`. Because that mount shadows the image's own home — which holds the agent binary at `/home/coder/.local/bin/claude` — each spawn image bakes a pristine copy of its home at `/opt/home-skel` and ships an entrypoint shim that runs `cp -an /opt/home-skel/. "$HOME/"` before exec'ing the command. `-n` (no-clobber) is what makes it copy-on-write: image updates appear automatically, user files are never overwritten. With one home mount covering `/home/coder`, the separate agent-state and auth mounts collapse into files written directly into the host home dir, removing all nested-mount concerns.

**Tech Stack:** Swift 6.3, swift-argument-parser, Swift `Testing` framework (`@Test`/`#expect`), Apple `container` CLI 1.2.2.

**Spec:** This document. The design was settled interactively on 2026-08-12; see "Design Decisions" and "Verified Facts" below. There is no separate spec file.

## Global Constraints

- Minimum Apple `container` CLI version: **1.2.2**. The design depends on VirtioFS host→guest uid mapping, verified on 1.2.2.
- Guest home path is exactly `/home/coder`; guest user is `coder` (uid 1001). Do not change either in this slice.
- COW home applies to **spawn-managed images only** (`--runtime spawn` / `auto`). Under `--runtime workspace-image` the user supplies the image, so there is no `/opt/home-skel`; that path must retain today's behavior unchanged.
- Swift style per `.swift-format`: no force unwrap, no force try, types marked `Sendable`, `guard` over deep nesting.
- `ValidationError` for CLI input errors, `SpawnError` for runtime failures.
- Always run `make test` before commit.

## Verified Facts

These were confirmed empirically on 2026-08-12 against `container` 1.2.2. Do not re-litigate them; do re-verify if the container version changes.

1. spawn images **already run non-root**: `id` reports `uid=1001(coder) gid=1001(coder) groups=1001(coder),27(sudo)`, `HOME=/home/coder`.
2. Files written by guest uid 1001 into a bind-mounted workspace land on the host owned by the **host user** (`mmayo:staff`). There is no ownership mismatch to fix.
3. A host file owned by uid 501 with mode `0600` appears inside the guest as `coder:coder 0600` and **is readable**. The premise behind `MountResolver.swift:54-58` (copy auth material to a state dir because VirtioFS preserves host uid) no longer holds.
4. Mounting any directory at `/home/coder` **completely shadows** the image's home: `which claude` fails and `ls -a /home/coder` shows only `.` and `..`. This is the constraint the skel/entrypoint design exists to solve.

## Design Decisions

- **Default home is shared, named `default`.** Agent OAuth tokens live in the home; a per-workspace default would force re-authentication in every repo. `--home <name>` opts into isolation and simultaneously delivers jai-style named sandboxes.
- **Auth material is written into the host home directory, not mounted separately.** With `/home/coder` itself mounted, separate mounts at `/home/coder/.ssh` would be nested mounts of uncertain support. Writing files into the host home before launch avoids the question entirely.
- **Agent state stops being a separate mount.** `~/.claude`, `~/.claude-state`, `~/.codex` are just directories inside the home now. Task 5 migrates existing state so users don't re-authenticate.
- **Out of scope, deliberately:** removing `NOPASSWD:ALL` sudo from the images (worth doing, unrelated to COW); replacing SSH key copying with `--ssh` agent forwarding; the `--runtime library` spike.

```swift
import ArgumentParser
import Foundation

/// Resolves the persistent, copy-on-write home directory mounted at `/home/coder`.
///
/// The host directory is seeded by the image's entrypoint from `/opt/home-skel`,
/// so it starts empty and fills in on first run.
enum HomeResolver: Sendable {
    /// Name used when the user does not pass `--home`.
    static let defaultName = "default"

    /// Guest mount point. Must match the `coder` user's home in the images.
    static let guestHome = "/home/coder"

    /// Validate a home name. Names become a single path component under `homes/`,
    /// so separators and traversal are rejected.
    static func validate(_ name: String) throws -> String {
        guard !name.isEmpty else {
            throw ValidationError("Home name must not be empty.")
        }
        guard !name.contains("/"), name != ".", name != ".." else {
            throw ValidationError(
                "Invalid home name: \(name). Use a simple name without '/'."
            )
        }
        return name
    }

    /// Host directory backing the named home.
    static func hostPath(name: String, stateDir: URL = Paths.stateDir) -> URL {
        stateDir
            .appendingPathComponent("homes")
            .appendingPathComponent(name)
    }

    /// Resolve and create the host home directory.
    static func ensure(
        name: String,
        stateDir: URL = Paths.stateDir,
        fileManager: FileManager = .default
    ) throws -> URL {
        let validated = try validate(name)
        let path = hostPath(name: validated, stateDir: stateDir)
        try fileManager.createDirectory(at: path, withIntermediateDirectories: true)
        return path
    }
}
```

```swift
/// Final layer for every spawn image: bake a pristine copy of the image's home
/// at `/opt/home-skel`, and install an entrypoint that seeds `$HOME` from it.
///
/// spawn mounts a persistent host directory over `/home/coder`, which shadows
/// everything the image put there (including `~/.local/bin/claude`). The
/// entrypoint restores it with `cp -an` — no-clobber, so image updates appear
/// automatically while anything the user or agent wrote is left untouched.
static let homeSkel = """
    USER root
    RUN rm -rf /opt/home-skel \\
        && cp -a /home/coder /opt/home-skel \\
        && chown -R coder:coder /opt/home-skel
    RUN printf '%s\\n' \\
            '#!/bin/sh' \\
            'cp -an /opt/home-skel/. "$HOME/" 2>/dev/null || true' \\
            'exec "$@"' \\
            > /usr/local/bin/spawn-entrypoint.sh \\
        && chmod +x /usr/local/bin/spawn-entrypoint.sh
    USER coder
    ENTRYPOINT ["/usr/local/bin/spawn-entrypoint.sh"]
    WORKDIR /workspace
    """
```

```swift
    case .js: template = js
    }
    // The skel must be the final layer so it captures toolchain additions
    // to /home/coder (.cargo, .bun, go/bin, ...).

}
```

```swift
/// Copy a host file into the persistent home, leaving any existing file alone.
/// The entrypoint's `cp -an` will not clobber what we write here.
private static func installIntoHome(
    _ source: URL,
    as name: String,
    home: URL,
    using fm: FileManager
) {
    let dest = home.appendingPathComponent(name)
    do {
        try? fm.removeItem(at: dest)
        try fm.copyItem(at: source, to: dest)
    } catch {
        logger.warning("Failed to install \(name) into home: \(error.localizedDescription)")
    }
}
```

Then, immediately after the read-only mounts loop (currently line 51), branch:

```swift
// Copy-on-write home: one mount covers all of /home/coder, so auth material
// and agent state are written into the host home rather than mounted separately.
if let home {
    mounts.append(Mount(hostPath: home.path, guestPath: HomeResolver.guestHome, readOnly: false))

    if access.mountsGitConfig {
        let gitconfig = homeDirectory.appendingPathComponent(".gitconfig")
        if fm.fileExists(atPath: gitconfig.path) {
            installIntoHome(gitconfig, as: ".gitconfig", home: home, using: fm)
        }
    }

    if access.mountsSSHKeys {
        let sshDir = homeDirectory.appendingPathComponent(".ssh")
        if fm.fileExists(atPath: sshDir.path) {
            let dest = home.appendingPathComponent(".ssh")
            ensureDirectory(dest, label: "home ssh", using: fm)
            let contents = (try? fm.contentsOfDirectory(atPath: sshDir.path)) ?? []
            for item in contents where shouldCopySSHItem(item) {
                let src = sshDir.appendingPathComponent(item)
                var isDir: ObjCBool = false
                guard fm.fileExists(atPath: src.path, isDirectory: &isDir), !isDir.boolValue else {
                    continue
                }
                let attrs = try? fm.attributesOfItem(atPath: src.path)
                if let type = attrs?[.type] as? FileAttributeType, type == .typeSymbolicLink {
                    continue
                }
                installIntoHome(src, as: ".ssh/\(item)", home: home, using: fm)
                if !item.hasSuffix(".pub") && !["known_hosts", "known_hosts.old", "config"].contains(item) {
                    try? fm.setAttributes(
                        [.posixPermissions: 0o600],
                        ofItemAtPath: dest.appendingPathComponent(item).path
                    )
                }
            }
        }
    }

    if access.mountsGitHubCLIConfig {
        let ghDir = homeDirectory.appendingPathComponent(".config/gh")
        if fm.fileExists(atPath: ghDir.path) {
            let dest = home.appendingPathComponent(".config/gh")
            ensureDirectory(dest, label: "home gh config", using: fm)
            for file in ["hosts.yml", "config.yml"] {
                let src = ghDir.appendingPathComponent(file)
                if fm.fileExists(atPath: src.path) {
                    installIntoHome(src, as: ".config/gh/\(file)", home: home, using: fm)
                }
            }
        }
    }

    return mounts
}
```

```swift
import Foundation

/// One-time migration of pre-COW-home agent state into the default home.
///
/// Before the copy-on-write home, agent state lived in per-agent directories that
/// were mounted individually. Those are now ordinary directories inside the home.
enum HomeMigrator: Sendable {
    private static let markerName = ".spawn-migrated"

    /// Legacy state directory → destination path relative to the home.
    private static let moves: [(legacy: String, destination: String)] = [
        ("claude-code/claude", ".claude"),
        ("claude-code/claude-state", ".claude-state"),
        ("codex/codex", ".codex"),
    ]

    /// Migrate legacy agent state if present. Idempotent — safe to call every run.
    @discardableResult
    static func migrateIfNeeded(
        stateDir: URL = Paths.stateDir,
        fileManager: FileManager = .default
    ) -> Bool {
        let fm = fileManager
        let home = HomeResolver.hostPath(name: HomeResolver.defaultName, stateDir: stateDir)
        let marker = home.appendingPathComponent(markerName)

        if fm.fileExists(atPath: marker.path) {
            return false
        }

        let present = moves.filter { fm.fileExists(atPath: stateDir.appendingPathComponent($0.legacy).path) }
        guard !present.isEmpty else {
            return false
        }

        do {
            try fm.createDirectory(at: home, withIntermediateDirectories: true)
        } catch {
            logger.warning("Failed to create home for migration: \(error.localizedDescription)")
            return false
        }

        for move in present {
            let source = stateDir.appendingPathComponent(move.legacy)
            let dest = home.appendingPathComponent(move.destination)
            // Never clobber: a home that already has state wins.
            guard !fm.fileExists(atPath: dest.path) else {
                continue
            }
            do {
                try fm.copyItem(at: source, to: dest)
                logger.debug("Migrated \(move.legacy) -> \(move.destination)")
            } catch {
                logger.warning("Failed to migrate \(move.legacy): \(error.localizedDescription)")
            }
        }

        try? Data().write(to: marker)
        print("Migrated existing agent state into ~/.local/state/spawn/homes/default/")
        return true
    }
}
```
